# 🎲 D&D Dice Engine for Owlbear Rodeo

A custom dice rolling extension for **Owlbear Rodeo 2.0**, tailored for **Dungeons & Dragons 5th Edition**. Supports advantage/disadvantage, exploding dice, keep highest/lowest, hidden GM rolls, and roll history.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Compatibility](https://img.shields.io/badge/OBR-2.0%2B-brightgreen)

---

## ✨ Features

- **Full Dice Set** – d4, d6, d8, d10, d12, d20, d100
- **Advantage / Disadvantage** – automatically rolls 2d20 and picks highest/lowest
- **Exploding Dice** – reroll on maximum value, sum all results
- **Keep Highest / Lowest** – roll N dice, keep only the top/bottom M
- **Modifiers** – add flat bonuses to your rolls
- **Hidden Rolls (GM only)** – roll secretly, visible only to the Game Master
- **Roll History** – keeps track of the last 50 rolls locally

---

## 🖥️ Interface

Clean, monochrome design with Deep Blue accent. Fits seamlessly into Owlbear Rodeo's dark/light themes.

## 📦 Installation

1. Download the latest release from [Releases](https://github.com/YOUR_USERNAME/owlbear-dice-engine/releases) (or clone this repo)
2. Open your **Owlbear Rodeo** room
3. Go to **Extensions** → **Add Extension** → **Install from File**
4. Select the `extension` folder (or the ZIP containing all files)
5. The dice panel will appear in your extensions dock

> **Note:** The extension uses the Owlbear Rodeo SDK, so it works
